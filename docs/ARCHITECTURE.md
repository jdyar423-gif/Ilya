# Ilya 架构说明

```
                ┌──────────────────────────── 共享上下文流（与问题无关，只算一次）───────────────────────────┐
 context ─► tok (+RoPE) ─► prelude ─► c₀ ──► [ctx_core]ᵀ  (权重共享的双向块，循环 T 次，每步注入 c₀)
                                              │ c₁ … c_T
                                              ▼ (只读 cross-attention)
 question m ─► [instr tokens ; NONE ; cand₁ … cand_K] ─► [ws_core]ᵀ (同样循环，每步注入 w₀)
                                   │                          │
            cand_k = MLP(mean tok(rubric_k 或 name_k))          ├─ 第 t 步读出: softmax([s_NONE, s_1..s_K])
            （无位置编码 → 集合；rubric 存在时 name 不进入模型）     └─ 置信度 ≥ τ 时该问题停机（anytime）
```

| 组件 | 作用 | 针对的 Jev 弱点 |
|---|---|---|
| 隔离的问题工作区 | 问题之间互不注意，答案不随同批问题变化；上下文只编码一次，所有问题共享 | W4（请求配置翻转）、保持 Jev 的"一次编码、多次决策"效率 |
| 候选即集合 | 候选 token 无位置编码，读出逐候选进行 → 对选项顺序**精确**等变 | W3（顺序可移动 13 个百分点） |
| rubric 权威绑定 | 选项语义 = rubric；名称只是返回给调用方的标识符，存在 rubric 时名称根本不进入模型 | W3（名称–rubric 互换后 AUROC .81→.58） |
| 隐式 NONE 结果 | 每个问题都有一个与候选竞争的 NONE 槽（choice / score / noul 全部适用），并用越界样本训练（outlier exposure） | W1（0/30 越界被标出） |
| 循环 anytime 核心 | 权重共享的块循环 T 次；每一步都用严格恰当评分规则（对数损失）监督 → 每步信念都是"给定目前计算量"的校准后验；推理时按置信度逐题停机，可跑得比训练更久 | W5（固定算力、无法深想） |
| 条件化一致性层 | 把调用方声明的逻辑约束作为证据，对隔离信念的乘积做**精确**条件化，返回一致的边缘分布、满足全部约束的联合 MAP，以及"支持度" P(C)（自相矛盾警报） | W4（个体判决不一致） |
| 统计保证层 | 温度缩放；Learn-then-Test 认证门限（以 ≥1−δ 概率保证选择性风险 ≤ ε）；分裂共形预测集；带"升级"动作的代价敏感决策 | W2（置信度不是契约） |

## 训练目标

对每次迭代 t 的读出都施加交叉熵（严格恰当评分规则），权重随 t 线性增加：

L = Σ_t w_t · CE(softmax([s_NONE, s_1..s_K])_t, y),   w_t ∝ t

y = 0 表示 NONE（越界 / 以上皆非）。与 RLCD 的目标一致（奖励 = 概率与实际正确频率的匹配），但直接用恰当评分规则做监督学习：在有标签时两者的最优解相同，而监督学习方差更小。

## 与 Jev 复刻版的公平性

- 同一个数据生成器、同样的批大小、优化器、学习率计划、训练步数；参数量匹配（约 84 万）。
- Jev 复刻版采用所有公开实现共同的机制：因果 LM、共享前缀 KV cache、按位置分配标签、在答案位读取标签 logits。
- 两个 Jev 变体：`jev`（封闭世界，只在界内数据上训练——它无法表达 NONE）与 `jev_none`（始终附加显式 "none of these" 选项，并与 Ilya 使用相同的越界训练数据——这比真实 Jev 更强，因为真实 Jev 的 score / noul 无法附加选项）。
- 所有模型在各自校准集上做温度缩放后再计算任何指标。
